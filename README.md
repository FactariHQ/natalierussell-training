# natalierussell.training

Website for Natalie Russell, personal trainer. Single static page served by GitHub Pages.

- Live: https://natalierussell.training (www redirects to the apex)
- `natalierusselltraining.com` redirects here via the `FactariHQ/natalierusselltraining-com` repo.
- DNS: Bluehost (Factari account). Apex A records → GitHub Pages; `www` CNAME → `factarihq.github.io`.

Edit `index.html` and push to `main` to publish. Yellow-highlighted `.ph` spans are placeholders for details still needed (prices, certification, contact info, photo, cancellation policy). The consult form is not yet wired to a backend.
